- Build a strong foundation. Correctness, security and data integrity take priority.
- This is a real system. Do not describe unfinished integrations or untested behavior as complete.

  Environment-enforced permissions remain separate technical constraints.

  Do not push every small edit separately.

  The latest user direction permits Azerbaijani conversation.
  Preserve original supplied evidence and necessary multilingual test fixtures.

inventory, authorization and tenant boundaries; real database integration tests;
duplicate-request and failure scenarios; and implementation/verification evidence
recorded in progress.md. Never promise zero defects or invulnerability.
